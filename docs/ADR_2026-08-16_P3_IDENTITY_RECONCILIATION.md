# ADR — P3 Project Identity Reconciliation

**Status:** accepted  
**Decision date:** 2026-08-16  
**Scope:** project identity and governance-document precedence for this repository

## Decision

The canonical project identity for this repository is **P3**.

The repository name `P1_PM10_Meteorology_Hstar` is historical and does not determine the canonical project number.

`docs/audit/P3_PROJECT_CANON.md` is the canonical project-definition document and project source of truth for P3.

`docs/ADR_2026-08-01_P2_IDENTITY_NORMALIZATION.md` is preserved as historical provenance and is superseded, with respect to this repository/project identity, by this ADR. The earlier P2 identity decision does not control the current identity on `main`.

## Scope boundary

This ADR resolves project identity only. It does not modify scientific content, scientific results, code, data, manuscript text, or the repository name.

This ADR does not modify or adjudicate the existing operational-meteorology statements or project-status statements contained in docs/audit/P3_PROJECT_CANON.md. Any subsequent change to the operational meteorology source, including the introduction of GFS, or any transition from HOLD_AND_REPAIR to active experimental work requires a separate explicit governance decision.

No experiment, rerun, forecast, or other scientific operation is authorized by this ADR.
