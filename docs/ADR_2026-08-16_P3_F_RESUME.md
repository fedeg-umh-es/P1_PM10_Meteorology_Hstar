# ADR — Explicit P3-F Resume Decision

**Status:** accepted
**Decision date:** 2026-08-16
**Project:** P3
**Line:** F — Forecasting & Operational Predictability
**Scope:** governance only

## Decision

P3-F is explicitly resumed for provenance and availability auditing only.

This does **not** authorize manuscript editing.

This does **not** authorize full forecasting experiments.

This does **not** authorize changes to validated Madrid–Ireland results.

Aurora 1.5 operational meteorology remains the canonical first operational-meteorology candidate. GFS is **not** authorized in this ADR.

The first authorized task is a single-origin Aurora 1.5 operational-meteorology provenance and availability pilot.

Scientific execution beyond that pilot requires a separate **PASS** decision.

P3-A remains **PARKED**.

No atmospheric-mechanism experiment is authorized.
